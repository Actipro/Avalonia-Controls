# 9/1/2026 - v26.2.0

## Docking
- Improved automation and accessibility capabilities (UIA).
## Fundamentals
- Added the AnimatedTextPresenter control for animated single-line text changes, perfect for dashboard values, counters, and status updates.
- Added the BorderBeam control for decorating content with traveling or pulsing borders, soft inner illumination, and theme-aware default colors.
- Added a sample demonstrating BorderBeam's interactive effect options, custom gradient stops, and normal border composition.
- Updated Badge to animate changes in string-based content when animation is enabled.
## Themes
- Added PlatformThemeSettings for accessing a visual's platform high-contrast preference and monitoring changes through its ColorValuesChanged event.
- Updated native control themes with changes in Avalonia through v12.1.2.
- Improved ModernTheme startup performance when AreNativeControlThemesEnabled is false by skipping native control style loading.
- Added Fundamentals, Bars, DataVisualization, and Docking options to ThemeStyleIncludes, allowing apps to selectively load Actipro product styles. The Pro and All options are now composites of their applicable individual options, and prerequisite product styles are automatically included.
- Fixed an issue where changing ModernTheme.Includes could remove StyleInclude instances that had been manually added to ModernTheme.
## Shared Library
- Added CanvasControl primitive for high-performance immediate-mode rendering and coordinated animation in custom controls.
- Updated TypedDataTemplateSelector to recycle an existing data template if the Type of the content did not change.
## All
- Updated the minimum Avalonia UI dependency from v12.0.0 to v12.1.2.
